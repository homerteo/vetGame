# Dra. Emiliana: Kinky-Kawaii Ortho-Gore

Simulador cómico de cirugía ortopédica veterinaria con gestión caótica del quirófano. Juego web en 3D estilizado (TypeScript + Three.js), con interfaz en español.

## Jugar en local

```bash
npm install
npm run dev
```

Abre http://127.0.0.1:5173/ en el navegador.

## Comandos

- `npm run dev`: servidor de desarrollo.
- `npm run build`: comprobación de tipos y compilación de producción en `dist/`.
- `npm test`: pruebas unitarias (Vitest).
- `npm run e2e`: pruebas end-to-end (Playwright; antes, `npx playwright install chromium`).

## Documentación

- `docs/GDD.md`: diseño del juego.
- `docs/ARCHITECTURE.md`: módulos y contratos.
